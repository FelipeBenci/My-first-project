My first project on GitHub.

Currency Converter (Static Version)
This is a simple and responsive currency converter interface built with HTML and CSS. It allows users to input the amount they want to convert and the current exchange rate.
Although it’s not functional yet, this project is part of my learning journey into front-end development. JavaScript integration will be added soon.
This project is a basic structure for a currency conversion web app. It was built using only HTML and CSS to practice layout, responsiveness, and clean UI design.
The logic for conversion is not implemented yet — I will add JavaScript functionality in the next steps of my learning process.
